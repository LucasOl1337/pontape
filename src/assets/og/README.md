# Fontes só pro build

Cópias TTF estáticas das fontes do site, usadas só pra desenhar o ícone e a prévia de compartilhamento no build (`src/lib/share/render.ts`). Não vão pro site: o navegador usa os woff2 de `public/fonts/`.

- `archivo-condensed-800.ttf`: Archivo, largura 75, peso 800.
- `atkinson-next-700.ttf`: Atkinson Hyperlegible Next, peso 700.

Licença SIL Open Font License 1.1, a mesma dos woff2. Os textos estão em `public/fonts/OFL-*.txt`.
