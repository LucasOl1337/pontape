# VidaNova (nome provisório)

Um projeto sem fins lucrativos e open source pra quem quer mudar de vida e não tem nem o primeiro passo.

A gente encontra a pessoa certa, conversa com ela por voz usando IA (ela não precisa saber ler), garante comida, roupa e higiene pros primeiros dias, e conecta com trabalho. Cada real doado aparece ao vivo, com comprovante.

Estado: fundação. Nada funcionando ainda.
